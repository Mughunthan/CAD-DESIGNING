# CAD-DESIGNING

## Boston Dynamics Spot Robot & Robotic Arm

This branch is dedicated to CAD designs and models related to Boston Dynamics Spot Robot and Robotic Arm projects. This repository contains CAD files, documentation, and resources for designing and modeling robotic systems.

### Features
- CAD models for Boston Dynamics Spot Robot
- Robotic Arm designs and specifications
- Engineering drawings and technical documentation
- 3D models and assemblies
